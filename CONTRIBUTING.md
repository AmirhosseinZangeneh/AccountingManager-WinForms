# Contributing

This repository is primarily maintained as a portfolio and educational project. Small bug fixes and focused improvements are welcome.

## Development setup

1. Follow the database and application setup in `README.md`.
2. Create a branch from `main`.
3. Keep changes focused and preserve compatibility with .NET Framework 4.8.
4. Run the scenarios in `docs/TESTING-CHECKLIST.md`.
5. Open a pull request that explains the problem, the change, and how it was tested.

## Commit style

Use short, descriptive commits where practical:

```text
feat: add transaction export
fix: preserve customer image on edit
refactor: centralize report filtering
docs: improve database setup guide
```
